# Mentions de tiers — MeneurTV

Ce document recense des composants ou données externes utilisés par MeneurTV.
Il ne remplace pas les fichiers `LICENSE` des paquets npm installés dans
`node_modules/` (consultez chaque paquet pour sa licence).

## Catalogue de métadonnées IPTV (iptv-org)

L’application consomme les fichiers JSON publics du projet **iptv-org / api** :

- URL des données : https://iptv-org.github.io/api/
- Dépôt : https://github.com/iptv-org/api

Le dépôt `iptv-org/api` est placé dans le **domaine public** (voir le fichier
`LICENSE` du dépôt : dédicace au domaine public, équivalent spirituel à l’*Unlicense*).

MeneurTV n’est **pas** affilié à iptv-org. Les flux listés relèvent de sources
tiers ; l’utilisateur reste seul responsable de la conformité de son usage avec
la loi locale et les conditions des diffuseurs.
